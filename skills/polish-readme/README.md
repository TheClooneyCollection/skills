# polish-readme

Polishes a project README's first screen and intro so it is accurate and quick to scan.

**Why:** A README's first screen decides whether anyone reads on, yet mine filled up with vague claims and stale badges. This makes it accurate and quick to scan.

**Use it:** ask to polish, tidy or redo a README.

## What it does

- Turns the intro into one line per feature, linking to its section, with details folded below.
- Adds badges that update themselves: CI, release, license, language version, platforms.
- Lays screenshots out in a grid with matching aspect ratios and realistic data.
- Checks every claim against the code and puts each warning next to the feature it is about.
- Makes Quick Start a single copy-paste block.
- Strips personal setup such as host names and private IPs.
- Ends with a list of what was done against what you asked, for you to review.
